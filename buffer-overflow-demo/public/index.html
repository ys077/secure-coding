Buffer Overflow Vulnerability Demonstration

A buffer overflow occurs when more data is supplied to a fixed-size memory buffer than it can hold. This demonstration simulates the condition using an 8-byte buffer.

  • Buffer Size: 8 bytes
  • Vulnerability: Buffer Overflow
  • Demonstration Type: Educational Simulation
  • Debugging Tool: GDB / OnlineGDB

Debugging Analysis

Web Application Demonstration = Simulation
Actual C/GDB Demonstration = Real memory-level behavior

The actual memory-level behavior is demonstrated using the vulnerable C program in OnlineGDB. Do NOT attempt to run GDB inside the browser.

char buffer[8];
char input[100];

// ... input reading ...

strcpy(buffer, input);

Debugging Procedure

  1. Set breakpoint at strcpy()
  2. Run the program
  3. Enter oversized input
  4. Observe buffer contents
  5. Execute next
  6. Execute continue
  7. Observe SIGSEGV / Segmentation fault

GDB Commands

break 17
next
continue

Expected Result

Program received signal SIGSEGV, Segmentation fault.
